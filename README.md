# Rock, Paper, Scissors Game 🪨 📄 ✂️

A fun, interactive Rock, Paper, Scissors game built with vanilla web technologies.

## 🚀 Features
* Play against a computer with randomized logic.
* Real-time score tracking.
* Responsive design (works on mobile and desktop).
* Clean, modern UI with CSS animations.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure.
* **CSS3:** Styling and layout.
* **JavaScript (ES6):** Game logic and DOM manipulation.

## 🕹️ How to Play
1. Clone the repository.
2. Open `index.html` in your browser.
3. Select your move and try to beat the machine!
